# Social preview card assets

These PNG files are lossless format conversions of the existing authentic card
scans in `public/cards/base1-4.webp` (Charizard) and `public/cards/ecard3-H30.webp`
(Umbreon). They retain the originals' dimensions and pixels. PNG is used because
the `next/og` rasterizer does not render the WebP data in the share poster.

The Pikachu scan and brand logo already use PNG and are read from their original
locations. No card artwork is generated or redrawn. See
`public/cards/sources.json` for the original scan sources and rights notice.
